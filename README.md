# Student Management System

A simple **Student Management System** built using Python. This project helps manage student records through a terminal-based interface and stores data in a JSON file.

## Features

- Add new student records
- Prevent duplicate Student IDs
- Validate student names and marks
- Calculate total marks and percentage
- Automatically assign grades
- View individual student report cards
- View all student records
- Search students by ID
- Store records using JSON

## Technologies Used

- Python
- JSON
- VS Code

## Subjects

The system manages marks for five subjects:

- Hindi
- English
- Mathematics
- Science
- Social Science

## Grading System

| Percentage | Grade |
|---|---|
| 90% and above | A+ |
| 70% – below 90% | A |
| 60% – below 70% | B |
| 33% – below 60% | C |
| Below 33% | D |

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/heyitssukumar/Student-Management-System.git
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python main.py
   ```

## Data Storage

Student records are stored in `student.json` using JSON format.
